# Student Performance Analysis - Summary

Dataset size: 500 students

## Correlation with Final Grade

|                      |   final_grade |
|:---------------------|--------------:|
| final_grade          |      1        |
| study_hours_per_week |      0.655573 |
| assignment_score     |      0.358933 |
| attendance_pct       |      0.264688 |
| previous_grade       |      0.234912 |

## Regression Model Performance

- R² score: 0.716 (71.6% of variance in final grade explained)
- Mean Absolute Error: 4.56 grade points

## Key Insight

Study hours per week and attendance percentage are the strongest predictors of final grade, ahead of previous academic performance. This suggests current engagement matters more than historical track record.
